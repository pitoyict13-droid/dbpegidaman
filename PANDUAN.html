SMP UNGGULAN IDAMAN BANJARBARU

Panduan Aplikasi Sistem Informasi Data Pokok Sekolah (Dapodik) & Persuratan

BAGIAN A — PANDUAN INSTALASI

A.1 Persyaratan

KebutuhanKeterangan
KomputerWindows 10/11 (juga bisa Linux/Mac)
JavaJDK 17 ke atas (sudah terpasang bersama Android Studio, atau unduh di adoptium.net)
DatabasePostgreSQL 16 (unduh di postgresql.org)
BrowserChrome / Edge / Firefox versi terbaru
JaringanServer dan HP/klien dalam satu jaringan (WiFi/LAN sekolah)

A.2 Menyiapkan Database PostgreSQL

  1. Pastikan PostgreSQL berjalan (layanan postgresql-x64-16 berstatus Running).
  2. Buka pgAdmin, buat database baru dengan perintah: CREATE DATABASE kepegawaian_smp;
  3. Kredensial bawaan aplikasi: Host localhost, Port 5432, user postgres, password postgres.
  4. Jika password sekolah berbeda, ubah di file src/main/resources/application.yml bagian spring.datasource.password.
ℹ️ Tabel database dibuat otomatis saat aplikasi pertama dijalankan — tidak perlu buat tabel manual.

A.3 Menjalankan Aplikasi

  1. Salin folder project kepegawaian-smp ke komputer server sekolah.
  2. Buka PowerShell / Command Prompt, masuk ke folder project: cd kepegawaian-smp
  3. Jalankan perintah berikut:
set JAVA_HOME=C:\Program Files\Android\Android Studio\jbr
.\mvnw.cmd spring-boot:run
  1. Tunggu hingga muncul: Tomcat started on port 8080
  2. Buka browser ke http://localhost:8080
  3. Untuk berhenti: tekan Ctrl + C atau tutup jendela PowerShell.

Agar otomatis jalan setiap komputer menyala (opsional)

Buat file JALANKAN-APLIKASI.bat di Desktop berisi:

@echo off
cd /d C:\lokasi\kepegawaian-smp
set JAVA_HOME=C:\Program Files\Android\Android Studio\jbr
call .\mvnw.cmd spring-boot:run
pause

A.4 Akses dari HP / Komputer Lain

  1. Di server, ketik ipconfig di PowerShell — catat IPv4 Address (contoh 192.168.1.10).
  2. Buka port 8080 di firewall: Windows Security → Firewall → Advanced settings → Inbound Rules → New Rule → Port → TCP 8080 → Allow.
  3. Dari HP/komputer lain (satu WiFi): buka http://192.168.1.10:8080
📱 Install di HP Android: buka alamat aplikasi di Chrome → menu ⋮ → Tambahkan ke layar utama. Aplikasi muncul dengan ikon sendiri.

BAGIAN B — PANDUAN PENGGUNAAN

B.1 Peran Pengguna

PeranHak Akses
ADMINMengelola semua data: profil sekolah, peserta didik, kesiswaan, sarana prasarana, pegawai, pengguna, surat, disposisi, laporan
STAFFHanya melihat data + mengelola disposisi miliknya sendiri

B.2 Login & Keluar

Isi username & password → klik Masuk. Setelah selesai bekerja, klik Keluar di kanan atas (token login langsung dicabut).

B.3 Ganti Password

Menu 🔑 Ganti Password → isi password lama, password baru (min. 6 karakter), konfirmasi → Simpan.

B.4 Kelola Pengguna (ADMIN)

Menu Pengguna → Tambah Pengguna: username, password, peran (ADMIN/STAFF), dan Nama Lengkap.

⚠️ Nama Lengkap harus sama persis dengan nama pegawai di Data Pegawai — nama inilah yang mencocokkan disposisi surat ke pemiliknya.

B.5 Dashboard

Ringkasan otomatis: total pegawai, guru & pimpinan, tenaga kependidikan, pegawai tetap, jumlah peserta didik aktif, item sarana prasarana & catatan prestasi, arsip surat masuk & keluar, plus grafik sebaran status kepegawaian, jabatan, dan kelas peserta didik.

B.6 Profil Sekolah 🏫

Menu Profil Sekolah menampilkan identitas lengkap sekolah (gaya Dapodik) — bisa dilihat semua pengguna; hanya ADMIN yang dapat mengubah. Data yang dikelola: nama sekolah, NPSN, NSS, status (Negeri/Swasta), bentuk pendidikan, akreditasi, tahun berdiri, kurikulum, waktu belajar, alamat & kontak lengkap, nama + NIP kepala sekolah, luas tanah/bangunan, daya listrik, sumber listrik, internet, serta visi & misi.

  1. Ubah (ADMIN): menu Profil Sekolah → edit isian → klik 💾 Simpan Profil.
  2. Pengguna STAFF melihat seluruh kolom dalam keadaan terkunci.

B.7 Peserta Didik 🎒

  • Tambah: tombol + Tambah Peserta Didik → isi NISN/NIS (boleh kosong, tidak boleh kembar), nama (wajib), jenis kelamin, agama, tempat/tanggal lahir, alamat, data orang tua/wali, kelas (mis. 7A), angkatan, status, tanggal masuk → Simpan.
  • Cari: ketik nama / NISN / NIS / kelas di kotak pencarian.
  • Ubah / Hapus: tombol ✏️ / 🗑 pada baris siswa. NISN & NIS bersifat unik.

B.8 Kesiswaan 🏆

Menu Kesiswaan mencatat hal-hal kesiswaan per peserta didik — jenis: Prestasi (isi Tingkat: Sekolah … Internasional), Pelanggaran (isi Poin Pelanggaran), Ekstrakurikuler, Beasiswa, atau Lainnya.

  1. Tambah: tombol + Tambah Catatan → pilih jenis, ketik nama siswa (saran otomatis dari data peserta didik), judul/kegiatan (wajib), tingkat, tanggal, poin, keterangan → Simpan.
  2. Cari: ketik nama siswa atau judul. Ubah/Hapus: tombol ✏️ / 🗑.

B.9 Sarana Prasarana 🔨

Menu Sarana Prasarana mengelola inventaris fisik sekolah (gaya Dapodik): kategori (Gedung, Ruang Kelas, Laboratorium, Perpustakaan, Ruang Kantor, Toilet/MCK, Lapangan/Olahraga, Alat Peraga/Peralatan, Furnitur/Mebel, Buku & Media, Lainnya).

  • Tambah: tombol + Tambah Sarpras → pilih kategori, isi nama (wajib), kode inventaris, jumlah, kondisi (Baik / Rusak Ringan / Rusak Sedang / Rusak Berat), luas m², tahun dibangun/pengadaan, sumber dana (BOS/APBD/APBN/…) → Simpan.
  • Cari & filter: kotak pencarian (nama/kode) dan dropdown kategori. Ubah/Hapus: tombol ✏️ / 🗑.

B.10 Data Pegawai

  • Tambah: tombol + Tambah → isi NIP (boleh kosong), nama, jenis kelamin, Status Kepegawaian (Pegawai Tetap / Pegawai Tidak Tetap), jabatan, mapel, pendidikan, tanggal, kontak, gaji, alamat → Simpan.
  • Cari: ketik nama di kotak pencarian. Ubah/Hapus: tombol ✏️ / 🗑 pada baris.

Import Excel (massal):

  1. Klik Template → unduh template-pegawai.xlsx.
  2. Isi data mulai baris ke-3. Kolom wajib: Nama, Jabatan, Status Kepegawaian. Format tanggal yyyy-MM-dd.
  3. Klik Import Excel → pilih file → Unggah.
  4. Sistem melaporkan berhasil/gagal per baris; data gagal diperbaiki lalu diunggah ulang — tidak ada data ganda (NIP unik).

B.11 Surat Masuk 📩

Menu Surat Masuk → Catat Surat Masuk:

KolomKeterangan
Nomor SuratNomor di kop surat pengirim, mis. 421.2/123/DISDIK/2026
KlasifikasiKode arsip Srikandi: UM, PT, SN, KP, UN, PG, PU, dst. (17 kode)
Tanggal SuratTanggal pada surat
PengirimInstansi/orang pengirim (wajib)
PerihalRingkasan isi surat
SifatBiasa / Penting / Segera / Rahasia
StatusBelum Diproses / Diproses / Selesai
LampiranScan/softcopy surat (PDF/gambar), maks. 10 MB
✨ Nomor agenda dibuat OTOMATIS format urut/kode klasifikasi/tahun — contoh 001/UM/2026, 002/UM/2026. Urut naik sendiri, reset tiap tahun, terpisah per kode klasifikasi dan per tipe surat. Tidak perlu diisi manual.

Tombol aksi pada tabel: 📤 Disposisi, ✏️ Ubah, 🗑 Hapus, 📎 Unduh lampiran.

B.12 Surat Keluar 📤

Sama seperti surat masuk, tetapi kolom Pengirim diganti Tujuan (kepada siapa surat dikirim), status menjadi Terkirim / Arsip, dan nomor agenda dihitung terpisah.

B.13 Disposisi Surat Masuk ✍️

  1. Buka Surat Masuk → klik tombol 📤 (Disposisi).
  2. Isi: Diteruskan Kepada (ketik nama — saran nama pegawai muncul otomatis), Instruksi Kepala Sekolah, Batas Waktu, status → Simpan.
  3. Satu surat boleh didisposisikan ke beberapa pegawai.

B.14 Notifikasi "Disposisi Saya" 🔔

  • Pegawai yang didisposisikan melihat lonceng di navbar dengan angka merah — diperbarui otomatis tiap 60 detik.
  • Klik lonceng / menu Disposisi Saya → daftar surat + instruksi + batas waktu (jika terlambat, ditandai merah).
  • Setelah selesai: klik ✅ Tandai Sudah Dikerjakan.
  • Disposisi hanya terlihat oleh penerima — data pegawai lain tetap aman.

B.15 Laporan Daftar Surat 📄

  • Export Excel — unduh Buku Agenda Surat berkop sekolah + tanda tangan Kepala Sekolah. Isinya mengikuti kata kunci pencarian yang aktif.
  • Cetak / PDF — tampilan A4 landscape berkop dengan logo. Untuk PDF: di dialog cetak pilih "Simpan sebagai PDF".

B.16 Rekap Persuratan 📈

Menu Rekap Surat: pilih tahun → kartu total, grafik per klasifikasi (masuk & keluar), grafik per bulan, dan tabel rekap Januari–Desember siap dilampirkan ke laporan.

B.17 Masalah Umum (FAQ)

MasalahPenyebab & Solusi

B.18 Keamanan & Backup Data

  • Login memakai token JWT (berlaku 12 jam); tombol Keluar langsung mencabut token.
  • Backup database secara rutin (contoh setiap Jumat):
pg_dump -U postgres -h localhost kepegawaian_smp > backup-kepegawaian.sql
  • Simpan file backup ke flashdisk/drive sekolah. Folder uploads/surat (berkas lampiran) juga perlu disalin saat backup.
